# Quiz Educacional

Projeto de extensão em React para estudos, com perguntas carregadas via JSON e feedback visual ao selecionar respostas.

## Funcionalidades

- Perguntas de vários níveis
- Indicação de respostas corretas e erradas
- Avanço automático para a próxima questão
- Estrutura simples para uso em sala de aula ou estudos

## Como rodar

npm install
npm start

## Tecnologias

- React
- JavaScript
- CSS
